> Для работы zapret нужен WinDivert - средство перехвата и фильтрации сетевого трафика, поэтому антивирус может отреагировать на его файлы.  
> WinDivert способен применяться как легитимными, так и вредоносными программами, однако сам по себе вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Некоторые антивирусы считают компоненты WinDivert потенциально опасными или относят их к хакерским инструментам. В результате файл удаляется и отправляется в карантин. Название обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса либо отключите обнаружение PUA, то есть потенциально нежелательных приложений. Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". При уверенной настройке исключений лучше добавить каталог в исключения; если вы не вполне понимаете назначение этих параметров, отключите детектирование PUA.

## ⚙️ Использование

1. Сначала включите безопасный DNS (Secure DNS).
    * В Chrome активируйте "Использовать безопасный DNS" и выберите DNS-провайдера, отличного от "Поставщика по умолчанию".
    * В Firefox откройте настройку "DNS через HTTPS", установите режим "Персональный", выберите пункт "Выбрать провайдера/поставщика" и укажите URL вручную. Например, подойдет `https://dns.google/dns-query`: провайдер Cloudflare может оказаться заблокирован.
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы. Инструкция находится [здесь](https://remontka.pro/dns-over-https-windows-11/); этот вариант рекомендуется пользователям Windows 11.
    * Владельцам роутеров Keenetic нужно активировать параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно.

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/Featherdrodepot89/zapret-discord-youtube/releases/latest).

3. Откройте свойства загруженного архива и включите флажок "Разблокировать". При использовании 7-Zip или PeaZip этот пункт можно пропустить.

4. Извлеките архив в каталог, путь к которому не содержит кириллицу и специальные символы.

5. Запустите подходящий файл:
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
    * Для добавления стратегии в автозагрузку выберите **`service.bat`** -> `Install Service` -> нужную стратегию.

## ℹ️ Кратко о файлах

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии ALT, FAKE и другие, пока не найдете подходящую для себя**.

- [**`service.bat`**](./service.bat) содержит установку автозапуска и дополнительные инструменты:
  - <ins>**`Install Service`** - добавляет выбранную стратегию в автозапуск через services.msc.</ins>
  - **`Remove Services`** - удаляет стратегию и WinDivert из списка служб.
  - **`Check Status`** - показывает состояние обхода и служб, включая автозапущенную стратегию и WinDivert.
  - **`Game Filter`** - включает или выключает отдельный режим для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После изменения этого режима стратегию необходимо перезапустить.**  
  Текущее состояние отображается в скобках: включено или выключено.
  - **`IPSet Filter`** - изменяет режим обработки сервисов из `ipset-all.txt`.  
  Это может пригодиться при проверке ресурса, который без zapret работает, а с ним - нет.  
  В скобках показывается текущий режим:
    - `none` - IP-адреса не проходят проверку
    - `loaded` - проверяется наличие IP в списке
    - `any` - под фильтр попадает любой IP  
  - **`Auto-Update Check`** - включает или отключает автоматическую проверку обновлений.
  - **`Replace active fakes`** - меняет текущий используемый fake на другой файл из каталога `bin`.
  - **`Update IPSet List`** - загружает актуальную версию `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** - обновляет hosts <ins>для восстановления веб-версии Telegram и подключения к голосовому чату Discord.</ins>
  - **`Check for Updates`** - вручную ищет доступные обновления.
  - **`Run Diagnostics`** - проверяет распространенные причины, из-за которых zapret может не запускаться или не работать.  
  В завершение можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапной остановки работы приложения.
  - **`Run Tests`** - запускает проверку стратегий:
    - `Standard tests` - проверяет сайты, перечисленные в `utils/targets.txt`
    - `DPI checkers` - проверяет DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️ Частые вопросы и проблемы

### После `general*` ничего не происходит

При запуске стратегии отдельным bat-файлом, а не через service, в панели задач должен появиться процесс winws.exe, отвечающий за обход.  
Если его нет, воспользуйтесь рекомендациями из [#522](https://github.com/Featherdrodepot89/zapret-discord-youtube/issues/522).

### Подходящей стратегии нет
- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер.

### Не открывается Telegram в браузере
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если используемый hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота.
  - В появившейся папке найдите файл `hosts` и откройте его текстовым редактором от имени администратора.
  - Вставьте скопированное в конец файла `hosts`; если аналогичные строки уже добавлялись, замените их.
  - Сохраните файл и проверьте подключение. Если результата нет, убедитесь, что hosts действительно был сохранен.

#### Работа не гарантируется. При отсутствии результата используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Featherdrodepot89/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии могут терять работоспособность со временем.**
> Вариант, который некоторое время успешно работал, позднее может перестать помогать после его обнаружения.
> Здесь собрано много стратегий обхода. Если все они не подходят, создайте собственную на базе одной из них, изменив параметры.
> Описание параметров доступно в [документации](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте результаты `service.bat` -> `Run Diagnostics` и устраните найденные ошибки.

- Убедитесь, что адрес нужного ресурса присутствует в списках доменов или IP-адресов.

- Испытайте другие варианты, включая **`ALT`**, **`FAKE`** и прочие стратегии.

- Выполните полную переустановку по инструкции ниже.

- Дополнительные сведения есть в [#765](https://github.com/Featherdrodepot89/zapret-discord-youtube/issues/765).

### Как полностью переустановить или обновить проект?
- Сохраните добавленные вами ресурсы и другие данные.
- Перезапустите компьютер.
- Откройте `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; исправьте ошибки и в конце подтвердите действие клавишей Y.
- Удалите текущий каталог zapret.
- Скачайте свежую версию `zapret-discord-youtube-...` со [страницы релизов](https://github.com/Featherdrodepot89/zapret-discord-youtube/releases).
- Щелкните по архиву правой кнопкой мыши и откройте свойства. Если внизу справа есть флажок разблокировки, включите его, нажмите "Применить", затем "ОК".
- Распакуйте архив в новый каталог в корне диска; в пути не должно быть пробелов и специальных символов.
- По очереди проверьте разные скрипты `general`. После каждой попытки проверяйте интернет-ресурсы. Если они недоступны, закройте программу через значок замка в панели задач и выберите другую стратегию.
- После нахождения рабочего варианта добавьте его в автозапуск: `service.bat` -> `Install Service` -> нужная стратегия.

### Игра или приложение не работает при включенном zapret

- В `service.bat` проверьте, что для `Game Filter` указано **`disabled`**, а для `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Инструкция по этой проблеме находится [здесь](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide).

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в каталоге [`bin`](./bin) одноименными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert остается среди служб

1. Узнайте имя службы в командной строке Windows. Откройте Win+R, введите `cmd`, затем выполните:

```cmd
driverquery | find "Divert"
```

2. Остановите найденную службу и удалите ее следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS](#%EF%B8%8Fиспользование) настроен.
- Отключите блокировщик рекламы: известно, что YouTube начал активно противодействовать таким расширениям.
- Переберите остальные стратегии, особенно если ранее выбранный вариант перестал работать.
- См. также [#251](https://github.com/Featherdrodepot89/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) включен.
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить ее.
- В `service.bat` откройте `Run Diagnostics` и выполните очистку кэша Discord.
- Проверьте, изменилось ли состояние приложения Discord после очистки.
- Откройте Discord в браузере по адресу https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей.
- Если Discord не открывается и в браузере, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- Дополнительные сведения: [#252](https://github.com/Featherdrodepot89/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/Featherdrodepot89/tg-ws-proxy).
- Также можно воспользоваться бесплатными MTProto-прокси из интернета.

### Не запускаются или не подключаются игры

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Начните с универсальной последовательности:
- через `service.bat` обновите ipset и активируйте `Game Filter`;
- если это не помогло, дополнительно включите `ipset any`.

Учтите: режим `ipset any` может нарушить открытие многих сайтов. Не оставляйте его включенным постоянно. Выясните IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`.

Если проблема останется, создайте обсуждение в разделе [Discussions](https://github.com/Featherdrodepot89/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Нужной проблемы нет в списке

- Опишите ее [в разделе issues](https://github.com/Featherdrodepot89/zapret-discord-youtube/issues).

## 🗒️ Как добавить адреса других ресурсов

Дополнительные адреса можно указать в следующих файлах:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически.
- **`list-exclude-user.txt`** - домены, которые нужно исключить, например когда IP сети есть в `ipset-all.txt`, но конкретный домен фильтровать не требуется.
- **`ipset-all.txt`** - отдельные IP-адреса и подсети.
- **`ipset-exclude-user.txt`** - IP-адреса и подсети, исключаемые из обработки.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
